# Product Dashboard

I recently completed a small independent React project — Product Dashboard. After completing my 14 Days of React Practice Challenge, I wanted to build something on my own to practice the React concepts I had reviewed.

## 🚀 Live Preview
* Live URL: [View Live Demo](https://your-vercel-link.vercel.app) *(Tomar Vercel live link ekhane diye dio)*

## ✨ Features
* Search products by name
* Set a maximum price
* Sort products by price (Low → High / High → Low)
* Sort products by name (A → Z / Z → A)
* Reset all filters
* See the filtered product count

## 🧠 What I Practiced
While building it, I practiced:
* `useState`
* `useMemo`
* Controlled inputs
* `filter()` and `sort()`
* `map()`
* State and derived data
* Dependency arrays
* Avoiding array mutation with the spread operator

## 💡 Reflection
This was a small project, but it helped me understand how different React concepts work together in a real application instead of practicing them separately.

My next goal is to continue building small projects and gradually improve my React skills.
